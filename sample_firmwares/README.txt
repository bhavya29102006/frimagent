FIRMAGENT LOCAL SAMPLE FIRMWARES
====================================
Use these files to test uploading custom firmware into FirmAgent!

1. 1_fan_controller.cpp
   - Arduino Uno + DHT22 temperature fan controller.
   - Language: C++ (Arduino)
   - Recommended Simulator: Wokwi or Universal Virtual Mock

2. 2_incubator_controller.cpp
   - Precision poultry/medical incubator thermostat with heater relay.
   - Language: C++ (Arduino)
   - Recommended Simulator: Wokwi or Universal Virtual Mock

3. 3_smart_door_lock.cpp
   - Security access control with master PIN, buzzer, LEDs and 3-attempt lockout.
   - Language: C++ (Arduino)
   - Recommended Simulator: Universal Virtual Mock or Wokwi

4. 4_water_tank_monitor.c
   - Industrial reservoir water level controller with pump cut-off and overflow alarm.
   - Language: Pure Embedded C
   - Recommended Simulator: Native C Runner or Universal Virtual Mock

5. 5_iot_weather_node.py
   - MicroPython ambient telemetry node with temperature and freeze warning.
   - Language: Python / MicroPython
   - Recommended Simulator: MicroPython Runner

6. 6_broken_syntax_demo.cpp
   - Deliberate syntax errors (missing semicolons) to showcase 1-Click AI Auto-Repair live!
   - Language: C++ (Arduino)

7. 7_ultrasonic_radar.cpp
   - Ultrasonic radar proximity scanner with servo sweep, distance telemetry & buzzer alarm.
   - Language: C++ (Arduino)
   - Recommended Simulator: Universal Virtual Mock or Wokwi

8. 8_robot_obstacle_avoidance.py
   - Autonomous differential drive robot with LiDAR ray scanner, obstacle avoidance & emergency brake.
   - Language: Python (ROS2 / Gazebo Node)
   - Recommended Simulator: Gazebo Robotics Simulator or MicroPython Runner
