06 / SAFETY & RELIABILITY

Deterministic Safety Gate & Zero-Regression Rule

🛡️ 7 Pre-Patch Safety Checks

  • • Hunk Count Limit: Maximum ≤ 3 hunks allowed.
  • • Line Count Limit: ≤ 25 total modified lines (no wild rewrites).
  • • Exact Byte Match: Replaced text must match original source byte-for-byte.
  • • Disjoint Hunks: Zero overlapping hunk line ranges.
  • • Protected Ranges: Headers, includes, and pin defines are locked.
  • • Spec Block Integrity: Docstring requirements cannot be altered.
  • • Compilation Gate: Must compile cleanly with 0 compiler errors.

🧪 Isolated Sandbox & Zero-Regression Rule

  • • Dedicated Clone: Patches are applied to an isolated copy in runs/.../project/.
  • • Idempotent Patching: Reads from pristine .orig backup.
  • • Zero-Regression Rule: If even 1 passing test fails, the patch is instantly auto-rejected.
  • • Zero-Fix Rejection: If 0 failed tests are resolved, fix is rejected.
  • • 1-Click Safe Rollback: Instant atomic rollback from backup.
Result: 100% of applied patches pass with zero regressions
Guaranteed Safety: Master code is never touched until sandbox verification passes 100%.
